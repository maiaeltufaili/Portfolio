System Architecture

Real-Time CDC Pipeline Architecture

Problem Solved: Dual-write problems occur when updating a database and cache separately, leading to state drift during failures.

Solution: The Transactional Outbox Pattern writes changes to an outbox table within the same DB transaction. Debezium streams WAL events through Redpanda to Redis, ensuring eventual consistency without slowing down user-facing APIs.

Concurrency Control

Flash Sale Engine Deep Dive

Atomic Inventory Control: Under high concurrency (1,000s req/sec), standard SQL transactions cause locks or race conditions. Redis single-threaded DECR guarantees ticket counts never cross below zero.

Persistence: Successful Redis reservations spawn asynchronous write tasks to PostgreSQL to permanently persist order records.
