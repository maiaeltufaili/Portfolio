# 🌸 Software Engineering Portfolio — Maia El Tufaili

A modern, responsive, and interactive developer portfolio website built to showcase my software engineering background, full-stack projects, distributed systems architecture, and technical skill set. 

Designed with an aesthetic glassmorphism UI, a soft dark-pink theme, custom particle physics background, and interactive project deep-dives.

---

## ✨ Features

- **Responsive & Mobile-First Layout**: Fully adaptable across mobile, tablet, and desktop viewports.
- **Interactive Project Filtering**: Filter featured projects by domain (*All*, *Distributed Systems*, *Backend Scale*, *Full-Stack*, *Frontend & UI*).
- **System Architecture Deep-Dives**: Modal popups providing technical specs, concurrency strategies, and design patterns for each featured project.
- **Integrated Contact System**: AJAX-driven contact form powered by Formspree and asynchronous handling.
- **Dynamic Canvas Animation**: Custom floating canvas particle physics engine rendered in pure JavaScript.
- **Optimized Performance**: Zero external heavy framework dependencies for instantaneous load speeds.

---

## 🛠️ Tech Stack

- **Structure**: HTML5 (Semantic & Accessible Markup)
- **Styling**: Modern CSS3 (CSS Variables, Flexbox, CSS Grid, Glassmorphism Backdrop Filters)
- **Scripting**: Vanilla JavaScript (DOM Manipulation, Canvas API, Fetch API, Async/Await)
- **Typography**: Space Grotesk & Plus Jakarta Sans via Google Fonts
